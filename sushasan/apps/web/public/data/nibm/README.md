# NIBM pilot — bundled evidence JSON

`nibm_mvp_demo.json` is a copy of `nibm_traffic_data/data/processed/nibm_mvp_demo.json` from the local traffic pipeline (19 signals, clusters, interventions).

The **live** `/dashboard/nibm` UI reads typed data from `lib/nibm-pilot-data.ts`. This public copy is for transparency, audits, and future client-side refresh without redeploying TS.
