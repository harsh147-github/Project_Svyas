# Sushaasan Soft-Launch Demo Kit

This folder contains the launch assets around the NIBM digital twin demo.

## Files

- `launch_voiceover_hinglish.md`
  Founder voiceover script for the 75-90 second launch cut.
- `launch_storyboard.md`
  Shot-by-shot sequence for recording and editing.
- `launch_ui_scene_list.md`
  Which dashboard moments to capture for each scene.
- `social_launch_copy.md`
  Launch captions and cutdown hooks for Instagram, LinkedIn, X, and Reddit.

## Demo Surface

- Primary screen to record:
  [dashboard/sushaasan_dashboard.html](../dashboard/sushaasan_dashboard.html)
- Seeded demo data:
  [data/seeds/nibm_digital_twin_demo.json](../data/seeds/nibm_digital_twin_demo.json)

## Record Flow

1. Open the dashboard in a browser.
2. Start from the hero and hook.
3. Move into the evidence wall.
4. Pan to the live ops map and active hotspot.
5. Show the root-cause cluster and causal chain panels.
6. End on the intervention stack, routing ladder, citizen role layer, and CTA.

## Message To Preserve

Sushaasan is not a grievance platform.  
It is a governance intelligence engine that turns scattered public reality into coordinated civic action.
